# alpha_star_law_8B_v2 评测报告

中国电子云自研法律大模型 **alpha_star_law_8B_v2** 在 **LawBench** 与 **LexEval** 两套中文法律评测集上的公开评测结果。

在线地址：<https://cestc-real.github.io/legal-llm-test-report/>

---

## 核心结论

在四个模型**统一关闭思考模式**的条件下，alpha_star_law_8B_v2 在两套评测集上总分均为第一：

| 评测集 | alpha_star_law_8B_v2 | Qwen3-8B（基座） | LegalOne-8B | qwen3_for_law | 较基座 | 较最高竞品 |
|---|---:|---:|---:|---:|---:|---:|
| LawBench | **55.39** | 44.37 | 44.47 | 43.97 | +11.02（+24.84%） | +10.92（+24.56%） |
| LexEval | **73.82** | 59.09 | 56.48 | 58.94 | +14.73（+24.93%） | +14.88（+25.25%） |
| 两榜等权平均 | **64.61** | 51.73 | 50.48 | 51.46 | +12.88（+24.90%） | +13.15（+25.55%） |

- **8 个能力维度全部第一**（LawBench L1/L2/L3，LexEval L1/L2/L3/L4/L6），较基座提升 6.48 至 22.64 分。
- **35 项任务中 27 项取得最高分**：LawBench 11/16、LexEval 16/19。
- 覆盖 **19,392 道**题目（LawBench 16 项任务 / 7,992 题，LexEval 19 项任务 / 11,400 题）。
- 输出稳定性显著更好：LawBench 无效回答 21/7,992（0.26%）、LexEval 1/11,400（0.01%）；同期 LegalOne-8B 为 9.90% 与 0.25%。

> **口径说明**
> - 「较基座」= 自研模型主分 − Qwen3-8B 基座主分。
> - 「较最高竞品」= 自研模型主分 − max(LegalOne-8B 主分, qwen3_for_law 主分)；通用基座不参与竞品比较。
> - **主分**：剔除复读、思考标签未闭合等无效回答后的有效得分。
> - **全量分**：无效回答计 0 并保留在分母中。
> - 法律伦理维度的领先幅度按表内取整值为 **22.64**（正文另有一处写作 22.63）。

## 数据与可复现性

页面上的每一个数值都由脚本从 `data/` 下的原始评测表格导出中生成，**不手工转录**：

```bash
python3 scripts/build_report_data.py data > assets/report.js
```

命令会把口径自校验结果输出到 stderr，同时写入 `assets/report.js` 的 `verification` 字段。

`data/` 中的 CSV 为原始评测表格的逐表导出，文件名前缀是表格序号，后缀是源表格标识（仅供生成器匹配）：

### 口径自校验

生成器每次运行都会做四项校验：

| 校验项 | 结果 |
|---|---|
| 头条数值：结论表 vs 总分表（自研分、基座分、较基座提升、较最高竞品提升、最高竞品得分） | 3 组共 **15 项全部一致** |
| 「较基座」= 自研主分 − 基座主分（任务级） | 35 行中 **0 行**与原表不符 |
| 「较最高竞品」= 自研主分 − max(LegalOne, qwen3_for_law)（任务级） | 35 行中 **24 行**与原表一致，另 **11 行**原表存的是口径不明的单值（见下） |
| 正文原话交叉验证 | 2/2 一致（「2-3 婚姻纠纷鉴定」30.04、「2-6 命名实体识别」18.20） |

**关于那 11 行**：任务级明细的「较最高竞品」列存在两种形态——部分行是「主分 / 全量」双值，部分行只存了一个数值（`1`、`1.021768707`、`0.1312` 等）。后者口径不明，本项目**不予沿用**，统一按公式重算，并在页面任务级明细末尾明确标注。

## 技术说明

- **纯静态站点**：无构建步骤、无第三方依赖，图表为原生 SVG 手绘，可直接用浏览器打开 `index.html`。
- 页面数据与渲染分离：`assets/report.js`（数据，自动生成）+ `assets/render.js`（渲染逻辑）。
- 部署：GitHub Actions（`.github/workflows/pages.yml`）在 `main` 分支推送后自动发布到 GitHub Pages。

```
.
├── index.html                 页面骨架
├── assets/
│   ├── style.css              样式（配色按功能分工：结构 / 自研 / 基座 / 竞品 / 语义）
│   ├── report.js              页面数据（自动生成，勿手改）
│   ├── render.js              渲染层（原生 JS）
│   └── img/                   中国电子云标识（浅色底 / 深色底两版）
├── data/                      原始评测表格导出（CSV，页面数值的唯一来源）
├── scripts/
│   ├── build_report_data.py   数据生成器（含口径自校验）
│   └── shot.py                无头浏览器截图工具（本地视觉验收用）
└── .github/workflows/pages.yml
```

## 边界

- 本项目数值是**统一关闭思考模式、单一评测时点**下的结果，不构成对其他模型在其他数据集或其他推理设置下的结论。
- 实际吞吐、延迟与 token 成本**未在本次评测中测量**。
- 开放式条号定位的表现是否与后训练阶段的知识漂移有关，需用训练前后的同口径对照验证。
- 法条提示对刑期预测分数的影响，需控制题目与其他输入条件后单独验证。
- 任务级分数只反映本次评测在单一设置下的表现，不能外推为模型在其他题型或其他数据集上的结论。
- LegalOne-8B 的模型卡描述其生成方式为「先思考后回答」，与本次统一关闭思考的评测设置存在适配差异。
- 任务级明细中部分竞品差值单元格为口径不明的单值，本项目按已验证公式统一重算并标注，不沿用原值。
